## Agent configuration

Once the agent is created, you can configure it by editing the settings in the UI. For getting this partucular usecase working you need to do the following:

1. Goto Agent's behavious setting and copy the prompt from the prompt library.
2. Update the openapi.yaml with the correct IP of the the API server.
3. Goto toolset in the agent's UI and click on add Add tools button.
4. Select the Open API option from it and paste the openapi.yaml file.
5. Test if the agent is working as expected using the "Talkt to the agent" button.
6. If everything is working as expected, you can save the agent and deploy it to start using it.
